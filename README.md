# Kandu Employee (web app)

The Kandu - Payroll and HR employee app for iPhone and iPad: https://bigoke.github.io/kandu-employee/

Employees open the iPhone link from their invitation in Safari, tap Share > Add to Home Screen, and sign in from the
new icon. This repository only holds the published files; the source is `web/` and `android/www` in Kandu
(built with `web/build.sh`). It holds no passwords or company data.
